## 🚀 Готовность к использованию

### 📦 Установка
```bash
# TypeScript/JavaScript
npm install @agentstack/sdk@1.0.0

# React
npm install @agentstack/react@1.0.0

# Python
pip install agentstack-sdk==1.0.0
```

### 💻 Использование
```typescript
// TypeScript/JavaScript
import { AgentStackSDK } from '@agentstack/sdk';

const sdk = new AgentStackSDK({
  apiBase: 'https://api.agentstack.com',
  apiKey: 'your_api_key'
});
```

```python
# Python
from agentstack_sdk import AgentStackSDK, SDKConfig

config = SDKConfig(
    api_base="https://api.agentstack.com",
    api_key="your_api_key"
)
sdk = AgentStackSDK(config)
```
