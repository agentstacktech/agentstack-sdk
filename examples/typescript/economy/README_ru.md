# Примеры Economy SDK

**EN:** [README.md](./README.md)

## Окружения

| Env | `AGENTSTACK_API_BASE` |
|-----|------------------------|
| Production (по умолчанию) | *(не задан)* → `https://agentstack.tech/api` |
| Локальный Core | `http://localhost:8000/api` |

## Локальная разработка

Запустите AgentStack core локально или задайте `AGENTSTACK_API_BASE=http://localhost:8000/api`.

Переменные для скриптов: `AGENTSTACK_EMAIL`, `AGENTSTACK_PASSWORD`, `PROJECT_ID`, `USER_ID` (по скрипту).
